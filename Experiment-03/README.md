# Lab Experiment 3: Gaussian Mixture Models and EM Algorithm

## 📌 Objective
To implement the Expectation-Maximization (EM) algorithm for Gaussian Mixture Models and perform soft clustering.

## 🛠️ Software / Tools Required
* Python 3.x
* NumPy
* Matplotlib
* Scikit-learn

## 📋 Procedure
1. Generate a synthetic 2D dataset with multiple Gaussian clusters.
2. Implement the E-step (compute responsibilities) and M-step (update parameters) of the EM algorithm from scratch.
3. Visualize the clusters and Gaussian ellipses after selected iterations.
4. Compare the results with `sklearn.mixture.GaussianMixture`.

## 🎯 Expected Outcome
Understanding of soft clustering, mixture models, and the EM algorithm.

## 📁 Files Included
* `experiment_03.ipynb` — Jupyter Notebook with complete implementation, code, and plots.
* `README.md` — Experiment overview and guidelines.

## 🚀 How to Run
1. Open Jupyter Notebook, VS Code, or Google Colab.
2. Ensure `numpy`, `matplotlib`, and `scikit-learn` are installed (`pip install numpy matplotlib scikit-learn`).
3. Run `experiment_03.ipynb` cell by cell.
