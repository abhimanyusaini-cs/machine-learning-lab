# Lab Experiment 2: Logistic Regression and Perceptron

## 📌 Objective
To implement Logistic Regression and the Perceptron learning algorithm for binary classification and compare their performance.

## 🛠️ Software / Tools Required
* Python 3.x
* NumPy
* Matplotlib
* Scikit-learn

## 📋 Procedure
1. Load the Breast Cancer dataset.
2. Implement Logistic Regression using Gradient Descent (with sigmoid activation) from scratch.
3. Implement the Perceptron learning rule from scratch.
4. Evaluate both models using Accuracy, Precision, Recall, and F1-Score.
5. Plot the decision boundary for a 2-feature subset of the data.

## 🎯 Expected Outcome
Clear understanding of linear classifiers and the difference between Perceptron and Logistic Regression.

## 📁 Files Included
* `experiment_02.ipynb` — Jupyter Notebook with complete implementation, code, and plots.
* `README.md` — Experiment overview and guidelines.

## 🚀 How to Run
1. Open Jupyter Notebook, VS Code, or Google Colab.
2. Ensure `numpy`, `matplotlib`, and `scikit-learn` are installed (`pip install numpy matplotlib scikit-learn`).
3. Run `experiment_02.ipynb` cell by cell.
