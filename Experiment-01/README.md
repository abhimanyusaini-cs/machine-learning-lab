# Lab Experiment 1: Linear Regression and Regularization

## 📌 Objective
To implement Linear Regression from scratch and using scikit-learn, and to study the effect of Ridge and Lasso regularization.

## 🛠️ Software / Tools Required
* Python 3.x
* NumPy
* Matplotlib
* Scikit-learn

## 📋 Procedure
1. Load the California Housing dataset (or any suitable regression dataset).
2. Implement Linear Regression using the Normal Equation and Gradient Descent from scratch.
3. Train the model using `sklearn.linear_model.LinearRegression`.
4. Apply Ridge and Lasso regularization and compare Mean Squared Error (MSE) and R² scores.
5. Plot the regression line / predicted vs. actual values.

## 📁 Files Included
* `experiment_01.ipynb` — Jupyter Notebook with complete implementation, code, and plots.
* `README.md` — Experiment overview and guidelines.
