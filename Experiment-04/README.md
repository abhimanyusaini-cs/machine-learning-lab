# Lab Experiment 4: Principal Component Analysis (PCA)

## 📌 Objective
To perform dimensionality reduction using PCA from scratch and using scikit-learn, and to visualize high-dimensional data.

## 🛠️ Software / Tools Required
* Python 3.x
* NumPy
* Matplotlib
* Scikit-learn

## 📋 Procedure
1. Load the Digits or Wine dataset.
2. Implement PCA by computing the covariance matrix and its eigenvectors from scratch.
3. Project the data onto the first two principal components and visualize.
4. Reconstruct the data and compute reconstruction error.
5. Compare results with `sklearn.decomposition.PCA` and plot explained variance ratio.

## 🎯 Expected Outcome
Understanding of dimensionality reduction, variance explanation, and data reconstruction.

## 📁 Files Included
* `experiment_04.ipynb` — Jupyter Notebook with complete implementation, code, and plots.
* `README.md` — Experiment overview and guidelines.

## 🚀 How to Run
1. Open Jupyter Notebook, VS Code, or Google Colab.
2. Ensure `numpy`, `matplotlib`, and `scikit-learn` are installed (`pip install numpy matplotlib scikit-learn`).
3. Run `experiment_04.ipynb` cell by cell.
